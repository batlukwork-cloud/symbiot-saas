# Начать здесь

Задача завтра: поставить Симбиот поверх уже существующего Obsidian vault клиента и ничего не сломать.

## Делать строго в таком порядке

1. Открыть Obsidian клиента и записать путь к нужному vault.
2. Закрыть Obsidian.
3. Запустить `00_PRECHECK_AND_BACKUP_VAULT.ps1`.
4. Вставить путь к vault.
5. Дождаться backup в `Desktop\SYM_CLIENT_VAULT_BACKUPS`.
6. Запустить `INSTALL_PLUGIN_TO_VAULT.ps1`.
7. Вставить тот же путь к vault.
8. Запустить `RUN_SYMBIOT_RC_CHECK.cmd`.
9. Дождаться сообщения `Release Candidate check пройден`.
10. Запустить `START_SYMBIOT_DESKTOP.cmd`.
11. Дождаться desktop-окна `Симбиот`.
    Если вместо рабочего экрана появился экран `Симбиот не смог открыть рабочий экран`, нажать `Повторить`; технический статус запуска лежит в `runtime_logs\SYM_DESKTOP_BOOT_STATUS_2026-07-22.json`.
12. Открыть Obsidian.
13. Включить `Community plugins`, если они выключены.
14. Включить плагин `Symbiot`.
15. Нажать значок `Symbiot`.
16. Нажать `Проверить connector`.
17. Нажать `Подключить vault`.
18. Нажать `Подготовить workspace`.
19. Открыть `API-ключи` и добавить ключ через интерфейс.
20. Открыть desktop-окно Симбиота и описать тестовую миссию обычными словами.
21. Нажать `Подготовить миссию`: до запуска LLM должны быть видны контракт результата, группа 2-5 ролей, источники, предварительный бюджет, паспорт и граф.
22. Нажать `Запустить`: должны появиться ответ LLM, файл результата, статус Validator и Trace SHA.
23. Добавить до трех окон и проверить `Сравнить LLM`.

## Что нельзя делать завтра без отдельного решения

- Не запускать массовую миграцию старых заметок клиента.
- Не переносить старые папки вручную.
- Не удалять старые роли, отчеты, входящие, источники и заметки.
- Не обещать клиенту удаленный интернет-доступ с телефона.
- Не обещать marketplace/public release.

## Что должно получиться

- Старый vault клиента остается на месте.
- Старые папки и заметки остаются на месте.
- Старые community plugins остаются включенными.
- Появляется плагин `Symbiot`.
- Открывается desktop-окно `Симбиот`.
- `RUN_SYMBIOT_RC_CHECK.cmd` создает отчет в `runtime_logs`.
- `START_SYMBIOT_DESKTOP.cmd` создает boot status в `runtime_logs`, чтобы было видно, поднялся ли connector.
- Появляется безопасная рабочая зона Симбиота.
- API-ключи управляются из интерфейса плагина.
- Главная миссия проходит `Gateway -> Router -> Role Registry -> Context Builder -> Role Runtime -> Validator -> Trace`.
- LLM Hub / desktop GUI открывает три окна.

Полная инструкция: `01_CLIENT_INSTALL_RU.md`.
